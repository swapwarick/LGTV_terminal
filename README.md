# webOS Terminal

A local shell terminal for LG webOS TV (5.x). Runs `/bin/sh` on the TV and streams it to an xterm.js UI via a local WebSocket connection.

## Architecture

```
[xterm.js in browser engine]  ←WebSocket ws://127.0.0.1:9001→  [Node.js service on TV]
                                                                        ↓
                                                                  /bin/sh (busybox)
```

The Node.js service is registered as an `immediate` background service — it starts automatically when the package is installed and stays running.

## Prerequisites

| Tool | Install |
|---|---|
| Node.js ≥ 18 (on your PC) | https://nodejs.org |
| webOS TV CLI | `npm install -g @webos-tools/cli` |
| LG Developer Mode | See below |

---

## Step 1 — Enable Developer Mode on your TV

1. Go to **Settings → About This TV**.
2. Click the **LG logo** 5 times rapidly → a Developer Mode dialog appears.
3. Sign in with an LG Developer account (free — create one at [webostv.developer.lge.com](https://webostv.developer.lge.com)).
4. Turn Developer Mode **ON** and **restart** the TV.
5. After reboot, go back to the same screen and note the **TV IP address**.

---

## Step 2 — Register the TV as an ares device

```powershell
ares-setup-device
```

Follow the prompts:
- **Device name**: `tv`
- **IP address**: your TV's IP (e.g. `192.168.1.50`)
- **Port**: `9922`
- **Username**: `prisoner`
- **Authentication**: password (leave blank or enter your passphrase)

Verify the connection:
```powershell
ares-device-info --device tv
```

---

## Step 3 — Build and deploy

```powershell
# Package only (produces .ipk in this directory)
.\build.ps1

# Package + install + launch on TV in one step
.\build.ps1 -Deploy
```

The build script:
1. Generates `app/icon.png` using .NET (no extra tools needed)
2. Runs `npm install` in the service directory
3. Runs `ares-package app service`
4. (If `-Deploy`) installs the `.ipk` and launches the app

---

## Manual commands (if you prefer)

```powershell
# Install dependencies
cd service; npm install --omit=dev; cd ..

# Package
ares-package .\app .\service --outdir .

# Install on TV
ares-install --device tv .\com.swapnil.lgterminal_1.0.0_all.ipk

# Launch
ares-launch --device tv com.swapnil.lgterminal

# View service logs live
ares-inspect --device tv --service com.swapnil.lgterminal.service
```

## Usage

- **Physical keyboard / Bluetooth keyboard**: just type — keys go directly to the shell.
- **Magic Remote**: point and click inside the terminal, then use the on-screen keyboard (Red button or input field tap).
- **Arrow keys** on any keyboard map to terminal escape sequences automatically.
- If the status bar shows **SERVICE NOT RUNNING** — reinstall the package; the service sometimes needs a TV restart after first install.

---

## Limitations

- No PTY (pseudo-terminal) — interactive ncurses apps (`vi`, `top`, `htop`) won't render correctly. Plain shell commands work fine.
- The shell runs as the TV's default user (usually `root` in Developer Mode).
- WebSocket is loopback-only (`127.0.0.1`) — not accessible from other devices on your network.
